# 공통 대시보드

브라우저와 Windows WebView2가 같은 대시보드를 표시합니다. 현재 센서값과 과거 차트는 같은 조회
스케줄러를 쓰며, 현재값으로 PC 접근을 확인한 뒤 과거값을 요청합니다. 갱신 주기는 3·5·10·30초 또는
수동입니다. 환경설정에는 갱신 주기만 저장합니다.

Node.js 24에서 `npm install`, `npm test`, `npm run build`를 실행합니다. `npm run dev`는 화면을
개발할 때 사용합니다. 인증과 실제 데이터를 확인하려면 대시보드와 사용자 API, 로그인 어댑터를
동일 HTTPS origin에서 제공하는 개발 게이트웨이를 사용하세요. 배포 및 인증 계약은
[S3-07 세션 계약](../docs/s3-07-session.md)을 따릅니다.
