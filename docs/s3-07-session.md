# S3-07 웹·Windows 앱 세션 계약

이 변경은 S2-03의 사용자 세션 테이블과 장비 자격 증명 분리, S3-03의 PC 소유권 검사,
S2-06의 조회 스케줄러를 사용한다.

| 응답 | 클라이언트 처리 |
| --- | --- |
| `401 USER_SESSION_EXPIRED` | 현재값·과거값 조회와 예약을 중단하고 화면/커서/측정값을 제거한다. 만료 이유와 로그인을 표시한다. |
| `401 USER_UNAUTHENTICATED` | 누락·무효·회수된 사용자 세션 또는 이전 세션 범위다. 같은 정리 후 로그인을 표시한다. |
| `404 MACHINE_NOT_FOUND` | 권한이 없거나 삭제된 PC다. 해당 PC의 값을 지우고 안내한다. 다른 PC는 조회할 수 있다. |
| 기타 오류 | 세션 확인 실패와 데이터 조회 실패를 구분한다. 인증 실패 응답은 재시도 대상이 아니다. |

- `GET /v1/user/session`은 서버가 확인한 세션 범위(`scope`)와 만료까지 남은 밀리초를 반환한다.
  세션 범위는 쿠키와 별도로 계산한 식별자다. 보호 요청의 `X-Pct-Session` 헤더에 넣어
  요청과 쿠키가 같은 세션을 가리키는지 확인한다. 범위만으로는 인증되지 않는다.
- `POST /v1/user/session/logout`은 요청에 결합된 사용자 세션만 회수한다. 장비 자격 증명과
  서비스에는 접근하지 않는다. 지연된 로그아웃 응답이 다른 탭의 새 쿠키를 지우지 않도록
  이전 쿠키는 서버에서 무효화하고 로그인 어댑터가 다음 로그인에서 교체한다. 네트워크 오류
  시 보호 화면을 닫은 상태로 명시적인 로그아웃 재시도를 제공한다.
- 화면은 서버가 준 만료 시한을 사용하고, 표시하는 동안 15초마다 및 화면 가시성 변경 시
  사용자 세션을 재확인한다. 수동 모드에서도 만료는 처리하되, PC 권한은 다음 PC 조회에서
  재확인한다. 세션 오류·로그아웃 후 현재값/과거값을 메모리에 유지하지 않는다.
- 다시 로그인하면 먼저 세션을 확인하고, 그 다음 현재값을 요청해 선택 PC의 소유권을
  확인한다. 재로그인 동선에서 같은 탭에 PC UUID만 일시 보존할 수 있다. 이전 센서값이나
  커서는 복원하지 않는다. 보호 응답 및 사용자 인증 오류는 `Cache-Control: no-store`다.
- 기존 사용자 `Authorization: Bearer` 계약을 유지한다. 장비 API는 사용자 쿠키를 읽지 않는다.
  WebView2는 Windows 사용자별 프로필에서 웹 쿠키를 관리하고, 수집 서비스와 프로필을 공유하지
  않는다. WebView2 메시지는 가시성 정보만 포함한다.

## 배포 전제

동일 HTTPS origin에 대시보드 빌드, `/v1/*` API, 로그인 어댑터의 `/login`을 배치한다.
로그인은 S2-03이 정의한 신뢰 어댑터가 실제 사용자 인증을 수행해 고엔트로피 세션을 만들고,
그 해시·사용자 ID·만료를 `user_sessions`에 저장하는 경로다. 다음 응답 헤더로 쿠키를
설정한 뒤 대시보드 루트로 돌려보낸다.

```http
Set-Cookie: __Host-pct_session=<opaque-value>; Path=/; Secure; HttpOnly; SameSite=Lax
```

쿠키에 `Domain`을 지정하지 않는다. 영속 쿠키를 발급하는 경우 수명은 DB 세션 만료 이내로
제한한다. URL, WebView2 메시지, 클라이언트 저장소에 비밀번호나 토큰을 전달하지 않는다.
WebView2는 외부 origin 이동을 기본 브라우저로 넘기므로 어댑터는 앱 내부에서 같은 origin으로
완료되는 로그인 경로가 필요하다. 운영 로그인 어댑터는 이 저장소에 포함되어 있지 않다.

기존 API DB 역할에는 로그아웃을 위해 `GRANT UPDATE (revoked) ON user_sessions TO <api_role>`을
추가한다. 세션 생성·만료 변경·삭제 권한은 부여하지 않는다. 현재값 조회에는 이미 수집/집계가
사용하는 `ingestion_batches`, `measurements`의 읽기 권한을 사용한다. 스키마 변경은 없다.
