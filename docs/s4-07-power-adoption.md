# S4-07 전력 예측 실험 이월 및 채택 기준

**이번 출시 범위에서 전력 예측을 보류한다.** 2026-11-21 02:19 KST에 확인한 결과, P0인 S4-05의 실제 PC 최종 재평가는 진행 전이고 전력 센서 지원·수집 증거도 확보되지 않았다. S4-07의 이월 조건을 적용한다. CPU·GPU의 실측 전력과 전력 예측은 지표를 구분한다. [S4-07 #47](https://github.com/SongWooSeok02/pc-telemetry-forecast/issues/47) · [S4-05 평가 계획과 검증 상태 #48](https://github.com/SongWooSeok02/pc-telemetry-forecast/pull/48)

| 대상 | 계획된 측정 범위와 단위 | 실제 센서 확인 | 채택 상태 |
| --- | --- | --- | --- |
| CPU | CPU 패키지 전력, W | PC별 센서 ID·측정 범위·지원 여부 미확인 | 보류 |
| GPU | GPU 보드 전력, W | PC별 센서 ID·측정 범위·지원 여부 미확인 | 보류 |

센서가 보고하는 범위는 PC와 드라이버별로 확인하고 표시명에는 해당 범위를 명시한다. 관측이 없는 PC는 지원 미확인으로 기록하고, 지원률은 확인한 PC·대상 가운데 지원하는 비율로 산출한다. 확인 대상이 0이면 N/A로 표시한다. 미지원·권한 오류·결측은 별도 사유로 집계한다. [실제 PC 센서 지원표](sensor-support.md)

## 실제 데이터가 확보되면 실행할 평가

1. **대상과 라벨 고정.** PC·센서마다 수집기/드라이버 버전, 센서 ID, CPU 패키지 또는 GPU 보드 범위, 단위 W, 확인된 측정 범위와 증거를 등록한다. UTC 1초 격자에서 기준 시각 `t`의 입력은 `[t-299초, t]`의 300개 관측이며, 정답은 `(t, t+60초]`의 품질 정상인 60개 전력 관측의 산술 평균이다. 센서 미지원·결측·장시간 공백·시계/품질 이상으로 입력이나 정답이 불완전한 창은 제외하고 사유와 건수를 기록한다.
2. **시간순 분리와 기준선 선택.** 학습 5일 이상, 검증 1일 이상, 독립 최종 평가 48시간 이상을 확보하고 입력과 정답이 같은 분할에 드는 표본만 평가한다. 최근 5분의 전력·부하·클럭 특징과 전처리는 학습 데이터에서만 결정한다. 현재 전력값 유지와 최근 5분 전력 이동평균을 모두 미래 60초 평균 정답에 대해 검증하고, 검증 MAE가 낮은 기준선을 고정한다. S2-07b와 S3-04의 점 시각 정답 계산은 평균 정답 규격에 맞춰 별도로 검증한다. 가공 규칙·모델·설정을 최종 구간을 열기 전에 고정하고, 추가 튜닝 시 새 최종 구간을 확보한다. [기준 평가 PR #21](https://github.com/SongWooSeok02/pc-telemetry-forecast/pull/21) · [온도 학습 PR #37](https://github.com/SongWooSeok02/pc-telemetry-forecast/pull/37)
3. **PC·대상별 성능 비교.** 동일한 유효 표본에서 기준선과 후보의 전체·유휴·고부하·전환 MAE(W), 표본 수, 결측률과 제외 사유를 보고한다. 구간 라벨은 S1-09 및 S4-05 평가와 대조한다. 독립 최종 구간에서 PC·대상별 유효 전환 10회 이상을 확보하고, 한 경계에 걸친 초별 표본은 같은 전환으로 센다. 전체 MAE 10% 이상 개선과 고부하·전환 MAE 각각 5% 이내 악화를 함께 충족해야 한다. 전체 기준 MAE가 1W 미만이면 검증에서 선정한 기준 모델을 유지한다. 구간 기준 MAE가 0이면 후보도 0일 때만 해당 악화 조건을 충족한다. 표본이나 센서 지원이 부족한 대상은 채택을 보류한다. [부하 전환 계획 PR #15](https://github.com/SongWooSeok02/pc-telemetry-forecast/pull/15) · [릴리스 평가 기준](../README.md#155-학습-데이터와-모델-채택)
4. **운영 비용과 노출 확인.** PC별 지원률, 수집 일수·원시 행 수·유효 창·전환 수와 함께 모델 크기, 동일 PC에서 기준/후보의 추론 지연 및 CPU·메모리, 서버 저장/전송 증가량을 기록한다. B와 함께 운영 빌드에서 P0 조회·수집 검증에 미치는 영향을 대조한다. 채택한 PC·센서에만 60초 평균 예측을 노출하며 웹·앱·API의 W 단위와 기간 의미가 보고서와 일치하는지 확인한다.
