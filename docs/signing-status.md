# S1-08 무료 배포 방식·코드 서명 필요성 재검토

기준일: 2026-11-03 KST. 담당: B (@SongWooSeok02), 설치 검증 협업: A.
상태: **방향 변경 반영·배포 경로와 실제 검증 대기, 완료 아님**.

## 결정

사용자 요청에 따라 무료 프로그램 배포를 기준으로 재검토한다. 유료 코드 서명
구매·신청·발급은 출시 필수 조건에서 제외한다. 실제 신청·결제·계약은 실행하지 않았다.
기존 발급 일일 추적 계획은 적용하지 않는다. 향후 유료 서명 도입은 비용·계약 별도 승인을 따른다.

배포 경로 제안은 이 저장소의 GitHub Releases에서 미서명 설치본과 SHA-256을 함께
제공하는 것이다. 기존 저장소를 배포 기준점으로 사용하고 별도 유료 서명을 구매하지
않는 방향에 맞춘다. A의 패키지 형식·드라이버 배포 조건 검토와 팀 리뷰 후 경로를 확정한다.
최종 공개 출시는 실제 설치·실행 검증 후 판단하며, 방향 결정만으로 검증 완료로 처리하지 않는다.

## 배포 경로 비교

| 검토안 | 확인할 조건 | 현재 판단 |
|---|---|---|
| 미서명 직접 배포 | 공식 다운로드 위치, 게시자 확인 제한 안내, 버전·SHA-256, 기본 설정에서 설치·실행 | 우선 검증안 |
| Store 등 다른 경로 | 계정 자격·비용 유무·패키지/서비스/드라이버 지원·심사·일정 | 대안, 적합성 미확인 |
| 유료 코드 서명 | 필요성·자격·총비용·키 관리·발급 일정·별도 승인 | 현재 구매·신청 범위 제외 |

미서명 파일은 인증서로 게시자를 확인할 수 없으며 Windows 경고나 환경별 실행 차단이
발생할 수 있다. 서명이 있어도 SmartScreen 무경고는 보장되지 않는다.
공식 근거: [Microsoft 평판 안내](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation),
[서명·배포 선택 안내](https://learn.microsoft.com/windows/apps/package-and-deploy/code-signing-options).
공식 자료 확인일: 2026-11-03 KST. 실제 경고·차단은 실측으로 판단한다.

## A 인계·검증 기준 (합의 대기)

- EXE/DLL/서비스/셸/설치 패키지 목록·형식·버전·배포 경로를 확정한다.
- 최종 파일의 SHA-256을 산출하고 공개 값과 대조한다. 파일 변경 시 다시 계산한다.
- 개발 도구 없는 Windows 11 x64 PC에서 실제 배포 경로로 다운로드하여 설치·실행·서비스 시작·삭제를 확인한다.
- OS 빌드·Defender/SmartScreen·Smart App Control 상태·다운로드 출처·인터넷 출처 표식 여부를 기록한다.
- 경고와 실행 차단을 구분한다. 보안 기능 해제·Defender 예외 추가를 설치 조건으로 삼지 않는다.
- 차단 시 원인·재현 조건·해결 담당·다음 확인일을 기록하고 배포 경로·지원 범위·출시 일정을 재검토한다.
- 센서 드라이버의 기존 서명·라이선스·권한·보안 호환성 검증은 유지한다.

각 검증은 빌드/버전·커밋·파일 SHA-256·PC 별칭·환경·재현 순서·기대값/실제값·
실행 시각(KST/UTC)·성공/실패·비밀을 제거한 로그/화면 참조를 남긴다.
개인정보·서명 키·비밀·결제자료를 저장소나 이슈에 넣지 않는다.

사용자 안내 초안: “무료 배포 프로그램입니다. 현재 설치 파일에는 코드 서명이 없어
Windows에서 게시자 확인 또는 실행 관련 경고가 표시될 수 있습니다. 공식 다운로드
위치와 버전·SHA-256을 확인하세요.” 실제 배포 위치·버전·검증 결과 확정 후 함께 게시한다.
체크섬은 파일 일치 확인 수단이며 게시자 인증을 대신하지 않는다.
