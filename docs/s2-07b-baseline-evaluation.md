# S2-07b 기준 모델 및 평가 파이프라인

## 결과

- `ml/evaluate_baselines.py`에 현재값 유지와 5분 이동 평균 기준을 구현했습니다.
- CLI는 PC·대상 센서 한 쌍씩 평가해 장기간·다중 PC CSV 전체를 메모리에 올리지 않도록 했습니다.
- 1초 관측 격자에서 직전 300초만 입력으로 사용하고 60초 뒤 정확한 관측값을 정답으로 사용합니다.
- 시간순 기본 분할은 학습 5일, 검증 1일, 테스트 48시간입니다. 각 분할 안에 입력 전체와 예측 목표가 들어오지 않는 경계 표본을 버립니다.
- 품질 이상·결측·비유한 값을 보간하지 않습니다. 창/정답에 그런 값이 있으면 해당 예제를 제외하고 가능한 앵커 대비 제외 비율을 기록합니다.
- 검증 구간의 MAE만으로 장비·센서별 기준을 고릅니다. 테스트는 선택에 사용하지 않으며, 선택한 기준과 나머지 기준의 테스트 MAE 차이를 보고합니다.
- 전체 및 `idle`/`high_load`/`transition` 라벨별 MAE·표본 수와 입력 SHA-256·실행 설정·경계를 JSON에 남깁니다.

## 재현 검증

- 환경: GitHub Actions Ubuntu/Windows, Python 3.12로 실행하도록 설정했습니다. 로컬 재현은 2026-11-28 KST Windows x64(10.0.26300) / Python 3.15.2에서 수행했습니다. 초기 작성 당시의 WindowsApps 실행 별칭 문제는 더 이상 해당하지 않습니다.
- 재현: `python -m unittest discover -s tests -p test_ml_baselines.py -v`
- 파이프라인 `s2-07b.3` 기준 고정 합성 시계열 단위 검증 10개(분할 경계·소수 초 앵커·정확한 48시간·결측 제외·검증 선택, `invalid_quality_rows` 행당 1회 집계 회귀 2개 포함)가 로컬에서 통과했고 `compileall`·`git diff --check`도 통과했습니다. 같은 검사를 두 OS CI에서 실행하며, 원격 CI 결과는 PR 확인란에서 별도로 확인합니다(최근 실행은 GitHub 계정 결제/지출 한도로 시작되지 못한 기록이 있습니다).
- 실행 기록: 합성 검증 데이터. 실제 PC/센서·부하 라벨 입력은 저장소에서 제공되지 않아 실측 MAE/결측률은 미실행입니다.
- 패키지 빌드: 별도 외부 패키지가 없는 순수 Python 모듈입니다.

CSV 규격, 실행 옵션, 데이터·라벨 한계는 [`ml/README.md`](../ml/README.md)에 있습니다. S1-09/S2-07a 입력 계약 확정과 실제 수집 데이터 검증이 남아 있습니다.
