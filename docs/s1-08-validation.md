상태: **문서 점검 완료, 실제 배포·설치 검증 및 공동 리뷰 대기**.
기반 커밋: `4e69449`. 제품 빌드/버전: 해당 없음(계획 문서 변경).
PC/환경: 현재 개발 작업 공간, Windows/PowerShell, Node.js. 실제 배포 대상 PC 아님.
실행일: 2026-11-03 KST. 정확한 실행 시각·환경·파일 해시는
[기계 판독 기록](s1-08-local-validation.json)을 참조한다.

| 점검 | 재현 방법 | 기대값 | 실제값·결과 |
|---|---|---|---|
| 변경 범위·공백 | `git diff --stat`, `git diff --check` | README 대상 범위만 변경, 공백 오류 없음 | 통과. 변경 줄의 공백과 줄바꿈 검사 |
| 로컬 문서 링크 | 변경 Markdown의 상대 파일 링크가 존재하는지 확인 | 대상 파일 존재 | 기계 판독 기록 참조 |
| 기존 신청 의무 제거 | README 7/15.2절 및 S1/S2/S3 작업명 확인 | 신청·발급이 필수 조건으로 남지 않음 | 반영. 센서 드라이버 요구사항 유지 |
| 실제 설치본 존재 | 추적 파일 중 Windows 프로젝트·설치 패키지 검색 | 검증할 설치본 식별 | 미확보, 실제 설치 검증 미실행 |
| 원격 카드 조회 | GitHub 연결 검색 및 기존 Git 인증의 Project GraphQL 조회 | 원격 카드 식별 | 연결 도구 접근 오류, Git 인증은 저장소 접근 성공·Project는 read:project 권한 부족. IssueDraft ID 미확인 |
| 다른 팀원 검토 | 승인 증거 확인 | 다른 팀원 1명 승인 | 대기. 자체 점검으로 대체하지 않음 |

문서 변경이므로 백엔드/DB 회귀 검사는 실행하지 않는다. 문서 점검 성공은
제품의 설치·실행 성공을 의미하지 않는다. 원격 카드 반영안은
[별도 문서](s1-08-card-revisions.md)에 준비했으며 게시·완료 처리는 하지 않았다.

## A/B 실제 배포 검증 기록 양식

아래는 미실행 양식이다. 기대값을 실제값으로 복사하거나 미실행 항목을 성공으로 처리하지 않는다.

| 필드 | 실행자가 채울 값 |
|---|---|
| 작업 ID·실행자·실행 시각(KST/UTC) | 미실행 |
| 빌드/버전·커밋·파일명·SHA-256 | 미확보 |
| PC 별칭·OS 빌드·개발 도구 유무 | 미기록 |
| Defender·SmartScreen·Smart App Control 상태 | 미기록 |
| 공식 다운로드 URL·다운로드 방법·인터넷 출처 표식 | 미기록 |
| 재현 순서 | 실제 배포 경로로 다운로드 → 해시 대조 → 기본 보안 설정에서 설치 → 서비스/앱 실행 → 삭제 |
| 기대값 | 공개 해시 일치, 안내와 관측 결과 일치, 지원 환경에서 설치·실행·삭제 성공 |
| 실제값·경고와 차단 구분·게시자 표시 | 미관측 |
| 성공/실패·비밀을 제거한 로그/화면 링크 | 미실행 |
| 실패 원인·해결 담당·다음 확인 시각·출시 영향 | 발생 시 기록 |

S3-09의 24시간 운영과 S5-07의 기존 통합 검증은 각 작업에서 별도로 기록한다.
